# Get Schooled Homepage

This project is part of the ALX Front-End Foundations curriculum.  
It is a simple homepage that introduces the **Get Schooled** platform and demonstrates basic HTML and CSS skills.

---

## 📌 Project Description

The goal of this project is to build a responsive homepage using:
- HTML5
- CSS3


The homepage includes key sections such as:
- Header with navigation
- Hero section
- Quote/testimonials
- Footer

This project helps reinforce:
- Structuring HTML pages
- Using semantic tags
- Organizing CSS files
- Styling content to match a given design

---

## 🗂️ Project Files

- `index.html` – Main HTML structure of the homepage  
- `styles.css` – Styling for the page  
- `images/` – Folder containing project images (if provided/used)  
- `README.md` – Project documentation
